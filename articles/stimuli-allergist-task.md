# Generating Stimuli for the Allergist Task

> **This copy was built without access to the OSF images, so the
> stimulus code is shown but not run. *Set-up* section below says how to
> run it.**

In this vignette, we use
[`catlasr::catlas_stimulus()`](https://josefmana.github.io/catlasr/reference/catlas_stimulus.md)
to generate and save stimuli, both cues and outcomes, for the Allergy
task used for replication and extension studies of Beesley and Le Pelley
(2011).

The stimuli consist of:

- **cues** comprising a name of a fictional chemical below a flask icon,
  and
- **outcomes** comprising a cartoon of potential side effect above its
  label

``` r

library(catlasr)
library(tibble)
library(gt)
```

## Set-up

Currently, images for stimulus generation are hosted on OSF. To access
them from R, you will need a Personal Access Token (PAT) for the
[osfr](https://docs.ropensci.org/osfr/) package.

1.  Ensure you are listed as a contributor on the private
    [CATLAS](https://osf.io/2shuc/) project.
2.  Create a PAT in your OSF account
    [settings](https://osf.io/settings/tokens).
3.  Open your `.Renviron` file via [usethis](https://usethis.r-lib.org),
    add the token as `OSF_PAT=<your token>`, and restart R:

``` r

usethis::edit_r_environ()
```

Before creating the stimuli, download materials from OSF to a temporary
directory:

``` r

temp_path <- file.path(tempdir(), "my_osfr_downloads")
dir.create(temp_path)

osfr::osf_retrieve_node("2shuc") |>
  osfr::osf_ls_files(n_max = 15) |>
  dplyr::filter(name == "stimuli") |>
  osfr::osf_download(temp_path, recurse = TRUE, conflicts = "rewrite")
```

## Cues

Since Beesley and Le Pelley (2011) do not provide the full list of
fictional chemicals used in their study, naming only *Addexium* and
*Rezaline* as examples, the current study uses chemical names from Le
Pelley et al. (2007). Not only did the latter study use the same
experimental design, but the authors also provided all 28 cue labels
employed by them.

Additionally, the two example chemical names from Beesley and Le Pelley
(2011) and four new fictitious chemical names generated using Google’s
Gemini (<https://gemini.google.com>) were added to be presented in
experiment tutorial.

------------------------------------------------------------------------

### Cue Stimulus Generation

To generate a cue stimulus, we need the flask image, and the stimulus
label. The flasks image for current study was generated by Gemini Nano
Banana 2 model to resemble images used in Scenario 2 of Le Pelley et al.
(2010).

The image is then:

- combined with appropriate label to yield cue stimulus via
  [`catlasr::render_stimulus()`](https://josefmana.github.io/catlasr/reference/render_stimulus.md)
- saved to the target location where experiment code lives via
  [`catlasr::write_stimulus()`](https://josefmana.github.io/catlasr/reference/write_stimulus.md)

``` r

flask_path <- file.path(
  temp_path,
  "stimuli",
  "templates",
  "allergy_task",
  "flasks.png"
)

#label <- "Ulginát" # Czech version
label <- "Ulginate" # English version

stim <-
  catlasr::catlas_stimulus(
    label = label,
    image_path = flask_path,
    type = "cue"
  )
  
img <-
  catlasr::render_stimulus(
    stim,
    width = 200, height = 200,
    font_size = 32,
    label_position = "bottom",
    label_shift = c(0, 20),
    background = "#c1c1c1"
  )

plot(img)
# Demonstration only, do not run
if (FALSE) {
  catlasr::write_stimulus(
    img,
    here::here(
      "forward-blocking-experiment",
      "stimuli",
      "cues",
      "Ulginate.png"
    )
  )
}
```

## Outcomes

Following Beesley and Le Pelley (2011), four outcomes were used for the
current study: dizziness, headache, itchiness, and nausea. Two further
outcomes, coughing and rash, were used in the tutorials.

Each outcome option consisted of a black-and-white cartoon depiction of
a man suffering given symptom accompanied by symptom label below the
picture.

For experimental trials, two fictitious patients, Mr. X and Mr. Y, were
generated, each suffering each of the four symptoms. For tutorial
trials, one fictitious patients, Mr. Z, was generated suffering the two
additional symptoms.

------------------------------------------------------------------------

### Outcome Stimulus Generation

Outcome stimuli are generated in much the same way as the cue stimuli,
using appropriate cartoon images available in the OSF repository
(downloaded earlier in this vignette).[^1] Each image is combined with
its label via
[`catlasr::render_stimulus()`](https://josefmana.github.io/catlasr/reference/render_stimulus.md)
and saved via
[`catlasr::write_stimulus()`](https://josefmana.github.io/catlasr/reference/write_stimulus.md).

``` r

image_path <- file.path(
  temp_path,
  "stimuli",
  "templates",
  "allergy_task",
  "z_coughing.png"
)

#label <- "kašel" # Czech version
label <- "coughing" # English version

stim <-
  catlasr::catlas_stimulus(
    label = label,
    image_path = image_path,
    type = "outcome"
  )
  
img <-
  catlasr::render_stimulus(
    stim,
    width = 400, height = 436,
    font_size = 66,
    label_position = "bottom",
    label_shift = c(0, 20),
    background = "#ffffff"
  )

plot(img)
# Demonstration only, do not run
if (FALSE) {
  catlasr::write_stimulus(
    img,
    here::here(
      "forward-blocking-experiment",
      "stimuli",
      "outcomes",
      "z_coughing.png"
    )
  )
}
```

## Conclusions

- This vignette demonstrates the generation of all stimuli required for
  the Allergist task replication and extension of Beesley and Le Pelley
  (2011).
- Cue stimuli (34 in total) were drawn from Le Pelley et al. (2007) (28
  names), Beesley and Le Pelley (2011) (2 names), and Gemini (4 tutorial
  names).
  - Nine conversion rules were applied to adapt English chemical names
    to Czech orthographic and phonological conventions, with all
    mappings documented in the rule book above.
- Outcome stimuli comprise six symptom images (four experimental, two
  tutorial), each rendered for fictitious patients in both languages.
