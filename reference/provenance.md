# Extract the provenance record of a CATLAS object

Extract the provenance record of a CATLAS object

## Usage

``` r
provenance(x, ...)

# Default S3 method
provenance(x, ...)

# S3 method for class 'catlas_rawdata'
provenance(x, ...)
```

## Arguments

- x:

  An object carrying a `catlas_provenance` record.

- ...:

  Currently unused.

## Value

An object of class `"catlas_provenance"`.
