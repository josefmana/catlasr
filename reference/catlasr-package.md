# The catlasr package provides CATLAS-specific R infrastructure, including experimental design data, theory-dependent models, and the import, validation and scoring of experimental data.

Provides datasets, modelling interfaces, and research utilities for the
\*Conditioning as a Theory of Learning, Attention, Semantics, and more\*
(CATLAS) project. Includes summaries of associative learning experiments
and effect sizes, tools for constructing and rendering experimental
stimuli, tools for preprocessing of experimental data, interfaces for
computational learning models (TBA) and utilities for producing
reproducible analyses and publication-ready outputs.
