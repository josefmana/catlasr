# Print a `catlas_provenance` record

Print a `catlas_provenance` record

## Usage

``` r
# S3 method for class 'catlas_provenance'
print(x, ...)
```

## Arguments

- x:

  A `catlas_provenance` object.

- ...:

  Passed to
  [`format.catlas_provenance()`](https://josefmana.github.io/catlasr/reference/format.catlas_provenance.md),
  e.g. `exclusions = "long"` to show the description of every exclusion
  rule.

## Value

`x` invisibly.
