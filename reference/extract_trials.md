# Extract the trial-responses component from a CATLAS raw-data bundle

Extract the trial-responses component from a CATLAS raw-data bundle

## Usage

``` r
extract_trials(x, ...)

# Default S3 method
extract_trials(x, ...)

# S3 method for class 'catlas_rawdata'
extract_trials(x, ...)
```

## Arguments

- x:

  A `catlas_rawdata` object.

- ...:

  Currently unused.

## Value

A tibble (one row per trial).
