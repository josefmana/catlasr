# Extract the stimulus-mappings component from a CATLAS raw-data bundle

Extract the stimulus-mappings component from a CATLAS raw-data bundle

## Usage

``` r
extract_stimuli(x, ...)

# Default S3 method
extract_stimuli(x, ...)

# S3 method for class 'catlas_rawdata'
extract_stimuli(x, ...)
```

## Arguments

- x:

  A `catlas_rawdata` object.

- ...:

  Currently unused.

## Value

A tibble (one row per participant).
